# Big Data Analytics Using PySpark

## 1. Project Overview

This project demonstrates the practical application of Big Data Analytics using Python, Apache Spark, PySpark, Spark SQL, and MLlib. It analyzes e-commerce transaction data to discover business insights, evaluate sales performance, understand customer purchasing behavior, and introduce predictive analytics.

The project is organized into five parts covering data exploration, descriptive analytics, customer analytics, advanced SQL analysis, and machine learning.

The notebook generates a synthetic e-commerce dataset and processes it using PySpark DataFrames and Spark SQL. It also applies Linear Regression, Random Forest Classification, and K-Means clustering to demonstrate different machine learning approaches.

### Project Objectives

- Generate and process e-commerce transaction data.
- Explore data using schemas, counts, and date ranges.
- Analyze revenue, products, categories, and regional performance.
- Examine customer spending, satisfaction, and order frequency.
- Use Spark SQL for advanced analytical queries.
- Build machine learning models for prediction and customer segmentation.
- Demonstrate how Big Data Analytics can support business decisions.

### Technical Workflow

1. **Data generation:** Create synthetic e-commerce transactions and save them as a CSV file.
2. **Data loading:** Define a schema and load the data into a Spark DataFrame.
3. **Data exploration:** Inspect the schema, sample records, order counts, customers, and transaction dates.
4. **Descriptive analytics:** Calculate revenue, average order value, and product and regional performance.
5. **Customer analytics:** Examine customer spending, satisfaction, payment methods, delivery times, and repeat orders.
6. **Spark SQL analysis:** Investigate monthly revenue, product rankings, discount correlations, busy days, and sales channels.
7. **Machine learning:** Train and evaluate predictive models and perform customer segmentation.
8. **Cleanup:** Stop the Spark session after completing the exercises.

### Machine Learning Documentation

- **Q21 — Linear Regression:** Predict transaction amounts using unit price, quantity, and discount.
- **Q22 — Random Forest Classification:** Predict customer satisfaction using transaction features.
- **Q23 — K-Means Clustering:** Group customers using spending, order frequency, and average satisfaction.

The notebook uses training and testing splits for the predictive models and reports model evaluation results. Actual performance depends on the generated data and model configuration.

## 3. Installation and Execution

### Prerequisites

- Python 3
- Java compatible with the installed Apache Spark version
- Jupyter Notebook, JupyterLab, or Google Colab
- PySpark

Install PySpark:

```bash
pip install pyspark
```

### Running the Project

1. Clone or download the repository.
2. Open `Nicodemebigdataassignment.ipynb`.
3. Run the dataset-generation cell.
4. Confirm that `ecommerce_sales.csv` has been created.
5. Execute the remaining cells in order.
6. Review the outputs for each exercise.
7. Allow the final cleanup cell to stop the Spark session.

For Google Colab, upload the notebook and run its cells in sequence, ensuring Java and PySpark are configured where required.
